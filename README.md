# Insurance Data Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing insurance policy sales data using **Microsoft Excel**.

The objective of the project is to transform raw insurance data into meaningful business insights through data cleaning, analysis, KPI calculation, pivot tables, charts, and an interactive Excel dashboard.

The analysis helps understand policy sales, customer behavior, premium amounts, coverage, claims, and overall insurance business performance.

---

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze insurance policy sales and performance
- Understand customer and policy trends
- Analyze premium and coverage amounts
- Identify important business KPIs
- Compare policy performance across different categories
- Identify key trends and patterns in the insurance data
- Build an interactive Excel dashboard for business reporting

## 📊 Project Workflow

### 1. Data Collection

The project uses insurance policy and sales datasets containing information related to customers, policies, premiums, coverage, and other insurance-related attributes.

### 2. Data Cleaning

The raw data was prepared for analysis by:

- Identifying missing values
- Removing duplicate records
- Checking data types
- Standardizing values
- Formatting dates
- Checking inconsistent or incorrect values
- Preparing the dataset for analysis

### 3. Data Analysis

Excel was used to perform analysis using:

- Pivot Tables
- Pivot Charts
- SUMIFS
- COUNTIFS
- IF
- IFERROR
- XLOOKUP
- Date-related formulas
- Other Excel functions

### 4. KPI Analysis

Important business metrics were calculated to evaluate insurance performance, such as:

- Total Policies
- Total Premium
- Total Coverage Amount
- Average Premium
- Average Coverage
- Policy Count by Category
- Policy Performance by Customer/Category
- Claims-related metrics where applicable

### 5. Dashboard

An Excel dashboard was created to provide a summarized view of the insurance business performance.

The dashboard contains:

- KPI cards
- Charts
- Policy analysis
- Premium analysis
- Category-wise analysis
- Interactive filtering where applicable
